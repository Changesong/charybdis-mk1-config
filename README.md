# ZMK-config for charybdis (4x6)

## Instructions
1. Turn both keyboards off
2. Connect USB cable to the left hand keyboard.
3. Double tap the reset button. Proceed when you see a "NiceNano" device pop up in your PC's devices.
4. Drag the "reset" firmware file on the device drive
5. Double tap the reset button again.
6. Drag the fw file onto the drive.
7. Repeat for the right half.
8. Power both keyboards on.
9. Re-pair bluetooth if needed.
