# ZMK-config for charybdis (4x6)

## Instructions
1. Turn both keyboards off
2. While holding down the reset button on the bottom of the left keyboard, connect it to the USB. After releasing the reset, you should see a drive showing up.
3. Drag the "reset" firmware file on the device drive
4. Drag the fw file onto the drive.
5. Repeat for the right half.
6. Power both keyboards on.
